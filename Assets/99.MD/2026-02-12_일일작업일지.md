# **일일 작업 일지 (2026-02-12)**

## **1. 작업 개요**
*   **목표**: 시스템 안정성 강화(NRE 해결), UI 시스템의 DLV(UIView) 패턴 리팩토링 및 Title 씬 시스템 구축.
*   **주요 성과**:
    1. **전투 비주얼 개선**: 몬스터 발사 위치를 `Controller` 본체 기준으로 고정하여 시각적 어색함 해결.
    2. **UI 아키텍처 정립**: `SubscribeManager` 중심의 중계 방식을 폐기하고, 개별 UI 뷰가 모델을 직접 구독하는 **UIView(Observer) 패턴**으로 전면 리팩토링.
    3. **선택지 시스템 안정화**: 레벨업 시 선택지 미출력 및 개수 부족 버그를 해결하고, `switch-case` 구조를 도입하여 확장성 확보.
    4. **Title 씬 기반 마련**: DLV 기반의 메인 메뉴 시스템과 Shapes를 활용한 고퀄리티 배경/UI 렌더러 구축.

## **2. 문제 사항 및 해결 (Issue & Resolution)**

### **[이슈 1] 레벨업 선택지 UI 미출력 및 개수 부족**
*   **현상**: 리팩토링 후 레벨업 시 UI가 뜨지 않거나, 선택지가 1~2개만 나타남.
*   **원인**: 
    1. 바인딩 순서 문제: 모델 생성 전 구독 시도.
    2. 중복 체크 로직 결함: 랜덤 추출 시 중복 ID가 나오면 재시도 없이 해당 슬롯을 비워버림.
*   **해결**:
    1. **External Binder**: `SubscribeManager`가 모델 초기화 후 명시적으로 `Bind()`를 호출하도록 구조 변경.
    2. **Robust Loop**: `while` 루프와 `safetyNet`을 도입하여 반드시 유니크한 3개의 선택지가 채워질 때까지 로직 수행.

### **[이슈 2] Title 배경 그리드 렌더링 품질 및 겹침 현상**
*   **현상**: 그리드가 움직일 때 겹치는 부분이 생겨 색상이 얼룩덜룩하게 보임 (Overdraw).
*   **원인**: Modulo(%) 연산을 이용한 개별 타일 이동 방식에서 경계선 중복 발생.
*   **해결**: 인게임 `HexGridRenderer`의 **가상 타겟 중심점 계산** 로직을 이식하여 각 좌표당 정확히 한 번만 그리도록 수정.

## **3. 상세 작업 내용**

### **[1] UI 시스템 전면 리팩토링 (UIView화)**
*   **대상**: `PlayerHPInLine`, `CircleEXP`, `IMEXPPanel`, `ChoiceUIView`.
*   **변경**: `SubscribeManager`의 중간 이벤트를 거치지 않고 `RuntimeDataPlayer` 모델을 직접 구독.
*   **이점**: 결합도(Coupling) 감소, 코드 명확성 증대, UI 갱신 성능 최적화.

### **[2] Title 씬 시스템 구축 (DLV)**
*   **[D] Data**: `DataHub.cs`에 `HasSaveFile` 프로퍼티 추가 (세이브 존재 여부 실시간 확인).
*   **[L] Logic**: `TitleLogicSystem.cs` 생성. 새 게임(데이터 초기화), 불러오기(데이터 유지 후 이동) 판단 로직 담당.
*   **[V] Visual**: 
    *   `TitleHexBackgroundRenderer`: 인게임과 동일한 규격의 무한 스크롤 배경 (Pulsing 효과 포함).
    *   `TitleShapesCanvas`: 화면 테두리 및 배경 박스 렌더링 (자동 카메라 연결).
    *   `TitleButtonPanel`: 버튼 전용 Shapes 패널. 마우스 오버 시 부드러운 색상 전환 피드백 제공.

## **4. 시스템 사용 가이드 (How-to-Use)**

### **① 신규 UI 컴포넌트 바인딩**
*   새로운 UI를 만들 때 `Bind(RuntimeData[Target] model)` 메서드를 구현하고, `SubscribeManager`의 `BindUIViews` 단계에서 연결해 주세요.

### **② Title 씬 구성 방법**
1.  **배경**: 빈 오브젝트에 `TitleHexBackgroundRenderer` 부착 후 `Base Color` 설정.
2.  **캔버스**: Canvas 오브젝트에 `TitleShapesCanvas` 부착 (카메라는 자동 할당됨).
3.  **버튼**: 각 버튼 오브젝트에 `TitleButtonPanel`과 `TitleButtonUIView` 부착.
4.  **연결**: `TitleUIView`의 리스트에 각 버튼을 할당하면 세이브 유무에 따른 'Load' 버튼 활성화 등이 자동 처리됨.
