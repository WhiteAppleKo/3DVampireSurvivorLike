# **일일 작업 일지 (2026-02-17)**

## **1. 작업 개요**
*   **목표**: 타이틀 및 인게임 증강 선택 UI의 하이브리드 스크롤 시스템 통합 리팩토링 및 주요 시스템 버그 수정.
*   **핵심 성과**: 
    1.  **UI 아키텍처 통합**: `BaseHybridScrollUIView`를 통한 중복 로직 제거 및 UX 일관성 확보.
    2.  **데이터 주도 실행 구조**: `IBindableUIContent.Apply()` 도입으로 데이터(SO)가 직접 로직을 수행하도록 변경.
    3.  **시스템 안정화**: 대시 공격 위치 오류, 경험치 자석 범위 무시 등 주요 게임 플레이 버그 해결.

---

## **2. 상세 작업 내용**

### **[1] 하이브리드 UI 시스템 통합 (Architecture)**
*   **`BaseHybridScrollUIView` (신규)**: 타이틀과 인게임에서 공통으로 사용되는 스크롤, 하이브리드 애니메이션(Lerp), 입력 처리 로직을 추상 클래스로 통합.
*   **`ButtonUIView` (통합)**: `TitleButtonUIView`와 `ChoiceButtonUIView`를 하나로 합쳐 유지보수성 향상. `applyOnClicked` 옵션으로 스크롤 버튼과 즉시 실행 버튼(Reroll 등) 구분.
*   **`TitleUIView` & `ChoiceUIView`**: 부모 클래스를 상속받아 각각의 비즈니스 로직(시간 정지, 데이터 바인딩 등)에만 집중하도록 리팩토링.

### **[2] 데이터 주도 설계 (Data-Driven)**
*   **`IBindableUIContent` 인터페이스 확장**: 모든 UI 콘텐츠 데이터가 스스로의 기능을 수행하는 `Apply()` 메서드 추가.
*   **`PureDataButton` (추상 클래스)**: 타이틀 전용 버튼들의 베이스 클래스 정의.
*   **구체 클래스 구현**: `TitleButton_NewGame`, `TitleButton_LoadGame`, `TitleButton_Exit`, `TitleButton_Confirm`, `TitleButton_Reroll` 등 각각의 독립적인 실행 로직 구현.
*   **인게임 증강 통합**: `PureDataStatAbility`, `PureDataWeaponAbility`, `PureDataWeapon`이 직접 플레이어 모델이나 무기 시스템에 접근하여 스스로를 적용하도록 변경.

### **[3] 주요 버그 수정 및 최적화 (Bug Fix)**
*   **DashAttack 위치 동기화**: `PureDataWeapon.Apply()` 시 무기 인스턴스의 로컬 좌표를 (0,0,0)으로 초기화하여 플레이어와 위치가 어긋나던 문제 해결.
*   **경험치 자석 로직 복구**: 스폰 시 무조건 추적하던 방식에서, `CircleEXP` 센서 범위 내 진입 시에만 추적을 시작하도록 로직 수정.
*   **UI 인터랙션 개선**: 
    *   버튼 클릭 시 `m_IsDragging` 상태를 강제 해제하여 스냅(Snap)이 씹히는 현상 수정.
    *   `ButtonPanel`의 호버(Hover) 색상 피드백 누락 로직 복구.
    *   선택 완료 시 UI 전체(`GameObject`)가 정상적으로 비활성화되도록 수정.

## **3. 인스펙터 설정 가이드 (유지보수)**

*   `Buttons` 리스트에 `ButtonUIView`가 부착된 오브젝트들을 순서대로 등록해야 스크롤이 정상 작동합니다.
*   `Main Panel`에 UI의 배경 컨테이너를 연결하세요.

### **[2] 개별 버튼 설정**
*   **선택지 버튼**: `Apply On Clicked`를 **해제(False)**로 두어 클릭 시 스냅만 되게 합니다.
*   **기능 버튼(Reroll, Confirm, NewGame 등)**: `Apply On Clicked`를 **체크(True)**로 두어 클릭 시 즉시 실행되게 합니다.
