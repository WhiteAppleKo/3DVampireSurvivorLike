# [기술 문서] UI 시스템 설계 및 하이브리드 UX

## **1. 개요**
본 문서는 프로젝트의 메인 메뉴(Title) 및 인게임 증강 선택(Choice) 시스템에 적용된 **하이브리드 UI(Hybrid UI)**의 설계 배경과 변천사를 다룹니다. 사용자 조작성(UX)과 시각적 연출력 사이의 균형을 맞추기 위한 의사결정 과정을 기록합니다.

---

## **2. UI 설계의 진화 과정 (3-Step Strategy)**

프로젝트 초기, 증강 시스템 및 정보 전달을 위해 두 가지 상반된 UI 접근 방식을 검토하였으며, 최종적으로 하이브리드 모델을 채택하였습니다.

### **[Step 1] 단순 스크롤식 (Initial Type)**
*   **특징:** 리스트를 밀어서 넘기는 스와이프/스크롤 중심의 UI.
*   **문제점:** 목록 이동 시 시각적인 재미는 있으나, 마우스로 특정 항목을 정밀하게 조작할 때 답답함과 피로도를 유발함.

### **[Step 2] 순수 클릭식 (Alternative Type)**
*   **특징:** 일반적인 버튼 형태의 고정형 그리드 UI.
*   **문제점:** 입력이 명확하고 빠르지만, 정적인 구조로 인해 본 프로젝트가 지향하는 사이버펑크 특유의 역동적인 연출력이 결여됨.

### **[Step 3] Hybrid UI (Final Design)**
*   **결과:** 스크롤의 **'동적 연출'**과 클릭의 **'명확한 입력'**을 결합한 형태.
*   **해결 방안:** 스크롤의 부드러운 움직임을 유지하면서도, 어느 위치에서든 사용자가 원하는 항목을 즉시 클릭하여 선택할 수 있는 구조로 최종 결정되었습니다.

---

## **3. Hybrid UI의 핵심 메커니즘**

결과적으로 구축된 시스템은 `BaseHybridScrollUIView`를 중심으로 다음과 같은 기술적 특징을 가집니다.

### **3.1 FocusScale 연출 (Dynamic Scaling)**
*   항목이 화면 중앙(포커스 영역)에 가까워질수록 크기와 광원 강도가 실시간으로 커지는 **`FocusScale`** 애니메이션(Lerp)을 적용합니다.
*   이를 통해 별도의 텍스트 강조 없이도 사용자가 현재 무엇을 선택하려는지 직관적으로 인지하게 합니다.

### **3.2 Hybrid Interaction System (직접 인터랙션)**
*   스크롤 위치와 상관없이 모든 UI 요소는 개별적인 클릭 이벤트를 유지하는 **`Hybrid Interaction System`**을 구축했습니다.
*   마우스 휠, 드래그, 버튼 직접 클릭이라는 세 가지 입력 방식을 모두 지원하여 조작의 자유도를 극대화했습니다.

### **3.3 통합 아키텍처 (Unified Architecture)**
*   **`BaseHybridScrollUIView`**: 공통 스크롤 및 애니메이션 로직 처리.
*   **`ButtonUIView`**: 데이터 바인딩 및 시각적 피드백 통합.
*   타이틀 메뉴와 인게임 UI가 동일한 기반 코드를 공유함으로써 유지보수 효율을 높이고 UX의 일관성을 확보했습니다.

---

## **4. 인게임 사이클 UI (하이브리드 버튼 제작 과정)**

### **4.1 문제와 해결 (Problem & Solution)**
*   **문제:** **스크롤 전용 UI**는 마우스 조작의 부정확함을 초래하여 사용자에게 스트레스를 주었고, **클릭 전용 UI**는 반복되는 게임 플레이(사이클)에서 연출의 단조로움을 유발했습니다.
*   **해결:** 스크롤 시 중앙 항목이 강조되는 **`FocusScale`** 연출과, 어떤 항목이든 즉시 클릭하여 선택할 수 있는 입력을 결합한 **`Hybrid Interaction System`**을 통해 이를 해결했습니다.

---

## **5. 하이브리드 시스템의 성과**
1.  **조작성 개선:** 정밀 조작 시의 답답함(조작의 부정확함)을 해결하여 사용자 피로도를 대폭 감소시켰습니다.
2.  **연출력 확보:** Shapes 에셋을 활용한 벡터 기반의 부드러운 애니메이션으로 사이버펑크 장르에 어울리는 고퀄리티 비주얼을 구현했습니다.
3.  **데이터 주도 설계:** ScriptableObject 기반의 `PureData` 시스템과 결합하여, 새로운 UI 항목 추가 시 별도의 코드 수정 없이 데이터 설정만으로 즉시 반영이 가능해졌습니다.
