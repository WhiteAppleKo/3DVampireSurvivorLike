# **일일 작업 일지 (2026-02-05)**

## **1. 리팩토링 개요**
*   **목표**: 모놀리식 구조의 기존 코드를 **DLV(Data-Logic-Visual) 아키텍처**로 전환하여 확장성과 유지보수성 확보.
*   **핵심 원칙**: 
    1. 모든 입력은 데이터화한다 (Input Command).
    2. 로직은 비주얼을 모른다 (Blind Logic via Interface).
    3. 데이터는 불변(Pure)과 가변(Runtime)을 철저히 분리한다.

---

## **2. 신규 스크립트 목록 및 기능 요약**

### **[플레이어 시스템]**
*   `RuntimeDataPlayer.cs`: 플레이어의 HP, 경험치, 레벨 상태 관리 및 이벤트 발송.
*   `PureDataPlayer.cs`: 플레이어의 초기 스탯 및 레벨업 테이블 정의 (SO).
*   `PlayerVisualizer.cs`: **Shapes 에셋**을 사용한 플레이어 이동 및 상태 시각화.
*   `IPlayerVisualizer.cs`: 플레이어 연출을 위한 인터페이스 규약.
*   `PlayerInputCommand.cs`: 입력을 데이터화하여 로직에 전달하는 구조체.

### **[무기 및 전투 시스템]**
*   `RuntimeDataWeapon.cs`: 무기별 실시간 쿨타임 및 증강 적용 최종 스탯 관리.
*   `WeaponVisualizer.cs`: 무기 공격 사운드 및 Shapes 기반 연출 담당.
*   `IWeaponVisualizer.cs`: 무기 연출 명령 인터페이스.
*   `PureDataProjectile.cs`: 투사체의 속도, 수명 등 불변 설정 (SO).
*   `RuntimeDataProjectile.cs`: 투사체의 화면 이탈 시간 및 타겟 상태 관리.
*   `ProjectileVisualizer.cs`: 투사체의 실질적 이동 및 물리 충돌(Trigger) 감지.
*   `IProjectileVisualizer.cs`: 투사체 제어를 위한 인터페이스 규약.

### **[경험치 시스템]**
*   `PureDataExpCristal.cs`: 보석의 추적 속도, 가속도, 획득 거리 설정 (SO).
*   `RuntimeDataExpCristal.cs`: 보석의 실시간 가속도 및 추적 상태 관리.
*   `ExpCristalVisualizer.cs`: 보석의 위치 업데이트 및 활성 상태 제어.
*   `IExpCristalVisualizer.cs`: 보석 연출 및 이동 명령 인터페이스 규약.

## **3. 수정 전/후 상세 비교 표**

| 항목 | 수정 전 (Legacy) | 수정 후 (DLV Architecture) |
| :--- | :--- | :--- |
| **EXP (경험치 보석)** | 단일 클래스에서 이동/획득 로직 처리. 변수 직접 수정. | `RuntimeData`가 상태를 관리하고 `Visualizer`는 이동만 수행. |
| **Weapon (무기)** | 데이터가 로직을 직접 수정함. 사운드/애니메이션이 로직에 종속. | **기존 CSV 임포터와 100% 호환**되면서 연출은 `Visualizer`로 위임. |
| **Projectile (투사체)** | 코루틴 기반의 복잡한 수명 관리 및 물리 직접 참조. | `Tick` 기반 상태 갱신 및 인터페이스를 통한 충돌 이벤트 전달. |
| **Player (플레이어)** | `Update`에서 직접 입력 체크 및 `Transform` 조작. | `InputCommand`로 입력을 분리하고 **Shapes 연출** 최적화. |
| **구조적 의존성** | 로직이 `Transform`, `Animator`, `Audio`를 직접 참조. | 인터페이스(`IVisualizer`)를 통해 엔진 종속성 제거 (Blind Logic). |

## **4. 리팩토링 코드 사용 가이드 (How-to-Use)**

### **① 신규 무기/경험치 아이템 추가 시**
1.  **데이터 설정**: `PureData` (SO) 에셋을 생성하거나 기존 CSV를 임포트하여 데이터를 준비합니다.
2.  **프리팹 구성**:
    *   오브젝트에 `System(Logic)` 클래스와 해당 `Visualizer`를 함께 부착합니다.
    *   **Pure Data** 슬롯에 준비한 데이터 에셋을 연결합니다.
3.  **Visual 연결**: `Visualizer` 인스펙터에서 제어할 **Shapes 컴포넌트**나 **사운드**를 연결합니다.

### **② 데이터 변화 감지 (UI 및 매니저)**
*   `Update`문에서 매 프레임 체크하는 대신, `RuntimeData`의 **이벤트를 구독**하세요.
*   **예시**: `playerController.Model.OnHpChanged += (cur, max) => { /* UI 갱신 */ };`

## **5. 주요 버그 수정 내역**
1.  **세이브 데이터 NRE 해결**: 데이터 클래스 기본 초기화를 통해 `null` 참조 방지.
2.  **무기 선택 UI 미출력 해결**: 무기 리스트가 비어있을 때도 첫 무기 선택지가 뜨도록 로직 강화.
3.  **이벤트 연결**: `BattleManager`가 새로운 DLV 모델에 경험치를 정상 주입하도록 수정.
