# **일일 작업 일지 (2026-02-06)**

## **1. 리팩토링 개요**
*   **목표**: 카메라, 몬스터, 스테이지 및 데이터 임포트 시스템 전반을 **DLV(Data-Logic-Visual) 아키텍처**로 전환하여 시스템 간 독립성을 확보하고 데이터 중심의 자동화 환경 구축.
*   **핵심 성과**: 
    1. 모든 외부 데이터(CSV)의 **PureData(SO) 및 Database**화 완료.
    2. 프리팹 수정 자동화(Missing Script 정리 및 필수 컴포넌트 자동 부착)를 통한 개발 생산성 향상.
    3. UI 선택 시스템의 데이터 무결성 확보 및 중복 선택 방지 로직 구현.

---

## **2. 신규 스크립트 목록 및 기능 요약**

### **[카메라 시스템]**
*   `CameraLogicSystem.cs`: 플레이어 추적 및 위치 계산 로직 (Logic).
*   `CameraVisualizer.cs`: 실제 카메라의 `transform.position` 갱신 (Visual).
*   `PureDataCamera.cs`: 카메라 오프셋, 추적 속도 설정 (Pure Data).

### **[몬스터 및 스테이지 시스템]**
*   `EnemyLogicSystem.cs`: 타겟 추적 AI 및 데미지 판정 제어 (Logic).
*   `EnemyVisualizer.cs`: 몬스터 이동, 회전 및 Shapes 기반 연출 (Visual).
*   `PureDataEnemy.cs` / `RuntimeDataEnemy.cs`: 몬스터 기본 스탯 및 실시간 상태 관리.
*   `PureDataStage.cs` / `PureDataBaseStage.cs`: 스테이지별 출현 몬스터 리스트 및 보스 정보 관리.

### **[데이터 임포트 시스템 (DLV 전용)]**
*   `MonsterImporter.cs`: CSV -> `PureDataEnemy` 생성 및 프리팹 자동 패치.
*   `WeaponImporter.cs`: CSV -> `PureDataWeapon` 생성 및 무기 프리팹 자동 패치.
*   `StatAbilityImporter.cs` / `WeaponAbilityImporter.cs`: 증강 데이터를 DLV 구조로 변환 및 DB 등록.
*   `StageImporter.cs`: 스테이지 데이터를 `PureDataBaseEnemy`와 연동하여 생성.

## **3. 수정 전/후 상세 비교 표**

| 항목 | 수정 전 (Legacy) | 수정 후 (DLV Architecture) |
| :--- | :--- | :--- |
| **Data Import** | CSV 데이터를 읽어 직접 프리팹이나 레거시 DB에 할당. | **CSV -> PureData(SO) -> PureDataBase**의 단방향 흐름 자동화. |
| **Prefab Management** | 스크립트 변경 시 Missing Script가 발생하여 저장이 안 됨. | 임포터가 **Missing Script 자동 제거 및 필수 컴포넌트 자동 부착** 후 저장. |
| **Camera** | `PlayerCamera` 단일 클래스에서 모든 처리. | 로직과 비주얼을 분리하여 엔진 종속성 최소화. |
| **UI Choice** | 데이터 교차 오염으로 인해 선택지가 중복되거나 잘못 생성됨. | `ClearAllData`와 **HashSet 기반 중복 방지 로직**으로 무결성 확보. |
| **ID System** | `int` 타입 사용으로 앞자리 '0'이 손실됨 (0300 -> 300). | `string` 타입으로 변경하여 **"0300" 형태의 ID 온전히 보존**. |

## **4. 리팩토링 코드 사용 가이드 (How-to-Use)**

### **① 데이터 최신화 (중요 순서)**
1.  **몬스터 임포트**: `Tools > Import MonsterDatas (DLV)` 실행 (프리팹 자동 패치 포함).
2.  **무기 임포트**: `Tools > Import WeaponDatas (DLV)` 실행.
3.  **스테이지 임포트**: `Tools > Import StageDatas (DLV)` 실행 (몬스터 DB 참조 필수).

### **② UI 선택 시스템 확장**
*   새로운 선택지 타입을 추가할 경우 `BindImageText.cs`에 Setter/Getter를 추가하고, `ChoiceApplySystem.ApplyAbility()`에서 분기 처리를 수행하세요.
*   모든 데이터 설정 시 `ClearAllData()`가 호출되도록 하여 데이터 오염을 방지해야 합니다.

## **5. 주요 버그 수정 내역**
1.  **프리팹 저장 불가 에러**: `RequireComponent` 위반 및 Missing Script가 포함된 프리팹을 임포터가 강제로 청소하고 필수 컴포넌트(`WeaponVisualizer` 등)를 부착하여 해결.
2.  **무기 중복 생성**: UI 슬롯의 이전 데이터가 남지 않도록 `BindImageText` 초기화 로직 강화.
3.  **ChargeDashWeapon 오작동**: 플레이어 사용 시 타겟 유무와 상관없이 전방 돌진하도록 로직 보강 및 공격 판정 위치 버그 수정.
4.  **체력 회복 미적용**: `ChoiceApplySystem`과 `RuntimeDataPlayer`를 연결하여 실제 HP 회복 및 UI 이벤트 발송 구현.
5.  **선택지 중복 출현**: `HashSet`을 이용한 ID 체크 로직을 `ChoiceSystem`에 추가하여 중복 항목 방지.
