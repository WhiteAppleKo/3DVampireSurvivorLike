# **일일 작업 일지 (2026-02-13)**

## **1. 작업 개요**
*   **목표**: Title 씬의 고급 버튼 시스템 구현 완료 및 누락된 상세 설계 내용 기록.
*   **주요 성과**:
    1. **데이터 주도 UI 구조**: ScriptableObject 기반의 버튼 데이터 바인딩 시스템 구축.
    2. **Shapes 기반 고퀄리티 렌더링**: 비트맵 이미지 대신 벡터 그래픽(Shapes)을 활용한 실시간 버튼 외형 구현.
    3. **가변 UX 애니메이션**: 마우스 거리 및 포커스 상태에 따른 부드러운 스케일링/색상 피드백 시스템 도입.

---

## **2. Title 씬 버튼 시스템 설계 상세**

### **[1] 데이터 구조 (Data)**
*   **`PureDataTitleButton` (ScriptableObject)**
    *   버튼의 논리적 ID(`NewGame`, `Load`, `Options`, `Exit`) 관리.
    *   UI 표시용 이름, 설명, 아이콘 스프라이트 포함.
    *   `IBindableUIContent` 인터페이스를 구현하여 기존 `BindImageText` 시스템과 호환성 유지.

### **[2] 시각적 구현 (Visual & UX)**
*   **`TitleButtonPanel` (Shapes Immediate Mode)**
    *   **실시간 렌더링**: `Draw.Rectangle` 및 `RectangleBorder`를 사용하여 테두리와 배경을 실시간으로 그림.
    *   **애니메이션 모드**:
        *   `FocusOnly`: 포커스 시 고정 배율(`focusScale`)로 확대.
        *   `Continuous`: 마우스와의 거리를 계산하여 가변적으로 확대(부드러운 상호작용).
    *   **상태 피드백**: Hover, Pressed, Disabled 상태에 따른 색상 보간(Lerp) 처리.

*   **`TitleButtonUIView`**
    *   데이터(`PureDataTitleButton`)를 받아 시각적 요소에 바인딩.
    *   버튼의 활성화/비활성화 상태에 따른 텍스트 색상 및 상호작용 제어.

### **[3] 비즈니스 로직 (Logic)**
*   **`TitleLogicSystem`**
    *   버튼 클릭 이벤트를 통합 처리.
    *   **NewGame**: `DataHub`를 통한 기존 데이터 삭제 및 게임 씬 이동.
    *   **Load**: 기존 데이터 로드 후 이동.
    *   **Exit**: 플랫폼별(Editor, Build) 종료 로직 처리.

## **3. 상세 작업 내용**

### **[1] 버튼 상호작용 최적화**
*   `ImmediateModePanel`을 상속받아 유니티 UI 시스템 위에서 Shapes 렌더링이 올바른 순서(Canvas 좌표계)로 수행되도록 구현.
*   `unscaledDeltaTime`을 사용하여 게임 일시정지 상태와 무관하게 부드러운 애니메이션 보장.

### **[2] 코드 가독성 및 유지보수성 향상**
*   각 컴포넌트(`UIView`, `Panel`, `Logic`) 간의 의존성을 최소화하여 UI 레이아웃 변경 시 로직 수정 없이 비주얼만 교체 가능하도록 설계.
